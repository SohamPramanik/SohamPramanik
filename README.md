## 🚀 Featured Projects

### 🤖 HireMind AI

**AI-Powered Interview Preparation Platform**

> A full-stack platform that helps users prepare for technical interviews using AI-generated questions, answer evaluation, scoring, and personalized feedback.

**Tech Stack:**
`React.js` `Node.js` `Express.js` `MongoDB` `Mongoose` `JWT` `Gemini API`

**Highlights**

* 🎯 Generates technical interview questions across multiple domains
* 🧠 Supports configurable difficulty levels
* 🤖 Uses Gemini API for answer evaluation and personalized feedback
* 🔐 JWT-based authentication and protected routes
* 📊 Tracks interview history, scores, progress, and results
* 🏗️ Built using REST APIs and MVC architecture
